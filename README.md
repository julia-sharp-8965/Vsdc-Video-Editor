## 🛠️ Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway** |
| Installer closes immediately | Reboot Windows and run the setup again from a local folder rather than a cloud synced path |
| App opens with a blank preview window | Update your GPU driver and confirm DirectX 11 or newer is available |
| Export finishes with audio drift | Match the project frame rate to the source clip rate before exporting |
| Preview playback stutters on 4K footage | Lower preview resolution in project settings or enable GPU decoding |
| Missing codec warning on import | Convert the file to H.264 MP4 or install the codec pack suggested by the app |
| Timeline becomes unresponsive with many clips | Split the project into smaller sequences and re-open the app |
